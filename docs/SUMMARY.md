# 学习路线

本教程按“新问题从哪里来”排序。下图是认知上的重建路线，不是数学史时间线。

```text
多个未知量需要同时满足条件
  -> 逐个消元，暴露唯一解、无解、多个自由选择
  -> 系数与运算重复出现，压缩成矩阵
  -> 一组相关数值需要作为整体处理，形成向量
  -> 展开矩阵乘向量，发现输入坐标在加权组合矩阵列
  -> 追问所有可能输出，进入张成与空间
  -> 追问描述是否冗余，进入线性无关、基与维数
  -> 追问对象如何作用于输入，进入线性变换
  -> 追问可逆性、解的结构与变换的不变量
  -> 追问长度、角度和最佳近似，进入正交、投影与最小二乘
  -> 特征向量无法覆盖一般变换，转向奇异值分解
  -> 用低秩结构理解近似、降维与数据
  -> 从原问题重建整个系统
```

## Phase 1：把方程看成结构

| 章 | 驱动问题 | 新能力 |
|---|---|---|
| [序言](book/00-preface.md) | 我们要学会什么，才算真正掌握？ | 用“问题压力”组织学习 |
| [线性方程](book/01-linear-equations.md) | 多个约束能否同时成立？ | 把解视为满足全部条件的对象 |
| [消元](book/02-elimination.md) | 怎样系统地处理多个方程？ | 用等价变形判断解的结构 |
| [矩阵](book/03-matrix.md) | 重复出现的系数和运算能否压缩？ | 将整个线性系统作为一个对象表示 |
| [向量](book/04-vector.md) | 怎样整体处理一组数和方向？ | 把输入、输出和变化作为整体研究 |
| [线性组合](book/05-linear-combination.md) | 矩阵作用后，输出由什么组成？ | 用加权组合解释矩阵乘向量 |

## 后续阶段

| 阶段 | 范围 | 核心压力 |
|---|---|---|
| Phase 2 | 张成、无关、基、维数、变换、乘法、逆 | 如何描述可达对象、冗余和作用规则？ |
| Phase 3 | 列空间、零空间、秩、秩-零化度 | 方程组的输出限制与自由度如何统一？ |
| Phase 4 | 特征向量、特征值、对角化 | 哪些方向在变换下保持简单？ |
| Phase 5 | 距离、正交、投影、最小二乘 | 无解时怎样得到最佳近似？ |
| Phase 6 | 特征分解局限、SVD、降维与数据 | 如何为一般变换找到稳定的方向结构？ |
| Phase 7 | 统一与最终重建 | 忘掉公式后，能否从原问题重建概念？ |

每个阶段结束时都应重建“前一概念为什么不够、下一概念如何补足”的关系，而不只复述术语。
