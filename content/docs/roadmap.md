本教程按“新问题从哪里来”排序。下图是认知上的重建路线，不是数学史时间线。读每个箭头时都补全这句话：**前一步让我能做什么；它又在哪里不够；因此下一步带来什么新能力？**

```text
多个未知量需要同时满足条件
  -> 逐个消元，暴露唯一解、无解、多个自由选择
  -> 系数与运算重复出现，压缩成矩阵
  -> 一组相关数值需要作为整体处理，形成向量
  -> 展开矩阵乘向量，发现输入坐标在加权组合矩阵列
  -> 追问所有可能输出，进入张成与空间
  -> 追问描述是否冗余，进入线性无关、基与维数
  -> 追问对象如何作用于输入，进入线性变换
  -> 追问可逆性、解的结构与变换的不变量
  -> 追问长度、角度和最佳近似，进入正交、投影与最小二乘
  -> 特征向量无法覆盖一般变换，转向奇异值分解
  -> 用低秩结构理解近似、降维与数据
  -> 从原问题重建整个系统
```

## 从具体到一般，我们怎样走？

第一至五章沿着一份配料记录推进：用量如何满足成分要求，方程怎样简化，成分表怎样成为矩阵，整份成分怎样成为向量。每一步都先算具体数字，再写通用规则。

第四至六章把相同的计算用于绳索受力。第十三章增加第三根绳子，解释为什么平衡方程不再决定唯一的拉力；第十八章从恒力做功理解内积。换场景时，我们检查坐标意义、单位与物理限制，确认哪些计算关系仍然成立。

最后只保留数学关系：任意实数系数、任意维数、一般矩阵，以及不依赖例子的证明。我们重建的是一条理解路径，不是在断言线性代数历史上一定由这些问题产生。

## 第一段：方程怎样长成结构

| 推进 | 已有能力与压力 | 新能力，以及它暴露的下一问 |
|---|---|---|
| [线性方程组]({{< relref "/book/ch01" >}}) | 单个等式能筛选候选值；多个条件要求共同满足。 | 把解看成交集；接着要可靠地简化整个系统。 |
| [消元]({{< relref "/book/ch02" >}}) | 手算能处理小系统，却难以追踪大系统的解集。 | 等价行操作揭示矛盾、主元与自由变量；重复操作需要统一表示。 |
| [矩阵]({{< relref "/book/ch03" >}}) | 消元反复处理系数，但散写方程掩盖了共同结构。 | 把系数与运算组织成对象；还要解释这个对象如何作用于输入。 |
| [向量]({{< relref "/book/ch04" >}}) | 输入输出是一组相关数，逐个书写会拆散整体。 | 用向量承载整体输入输出；接着追问矩阵怎样组合它们。 |
| [线性组合]({{< relref "/book/ch05" >}}) | 按行计算能给出答案，却不显示输入坐标如何共同作用。 | 按列重组得到加权组合；于是可以追问哪些输出可达。 |
| [张成]({{< relref "/book/ch06" >}}) | 列的组合能生成输出，但不同列能生成的目标并不相同。 | 描述所有可达向量；接着要问这份描述里有没有重复方向。 |
| [线性无关]({{< relref "/book/ch07" >}}) | 同一个输出可能由不同的系数拼出，说明有些列重复了信息。 | 识别并删去冗余方向；再用最少的向量描述同一个空间。 |
| [基]({{< relref "/book/ch08" >}}) | 只知道哪些列冗余，还缺一套简洁、完整的空间描述。 | 用线性无关且张成空间的向量组表示对象；接着追问基的向量个数是否固定。 |
| [维数]({{< relref "/book/ch09" >}}) | 同一个空间可以换基，需要一个不随基改变的大小。 | 基的个数固定，给出空间的维数；接着研究矩阵如何作用于基和整个空间。 |
| [线性变换]({{< relref "/book/ch10" >}}) | 逐点计算不能说明整个空间怎样变化。 | 保留线性组合，基的去向决定所有输入的去向；接着把接连执行的变换合成一次。 |
| [矩阵乘法]({{< relref "/book/ch11" >}}) | 每个输入都要连续计算多步；需要预先合成整个过程。 | 跟踪基的完整路线，把变换复合写成矩阵乘积；接着问能否撤销变换。 |

## 第二段：变换保留与丢失什么

| 章节 | 眼前的问题 | 新能力 |
|---|---|---|
| [12 逆矩阵]({{< relref "/book/ch12" >}}) | 从输出能恢复输入吗？ | 撤销完整变换，区分信息保留与输入合并。 |
| [13 列空间与零空间]({{< relref "/book/ch13" >}}) | 不唯一时，如何写全所有解？ | 先判断目标可达，再以一个解加零空间描述全部解。 |
| [14 秩与自由度]({{< relref "/book/ch14" >}}) | 看见与丢掉的方向各有几个？ | 用主元与自由变量推导秩-零化度，检查行间相容关系。 |
| [15 特征方向]({{< relref "/book/ch15" >}}) | 同一作用反复执行会怎样？ | 沿简单方向解释稳定、衰减与放大。 |
| [16 行列式]({{< relref "/book/ch16" >}}) | 能否用一个数检查压扁与可逆？ | 用带方向的面积或体积描述缩放，计算特征值条件。 |
| [17 对角化]({{< relref "/book/ch17" >}}) | 如何计算任意输入的反复作用？ | 换成完整特征基独立缩放，同时识别缺少特征基的限制。 |

## 第三段：精确解之外

| 章节 | 眼前的问题 | 新能力 |
|---|---|---|
| [18 内积与距离]({{< relref "/book/ch18" >}}) | 什么叫更接近？ | 指定长度、误差刻度与正交关系。 |
| [19 投影]({{< relref "/book/ch19" >}}) | 目标到不了，最近的可达点在哪里？ | 用垂直残差证明最近点。 |
| [20 最小二乘]({{< relref "/book/ch20" >}}) | 观测冲突，怎样共同解释？ | 找误差平方最小的系数与预测。 |
| [21 QR]({{< relref "/book/ch21" >}}) | 重叠方向让投影与求解繁琐。 | 构造正交基，把拟合化为上三角回代。 |
| [22 SVD]({{< relref "/book/ch22" >}}) | 非方阵或没有特征基，怎样拆作用？ | 输入输出各选正交基，统一缩放、秩与伪逆。 |
| [23 低秩近似]({{< relref "/book/ch23" >}}) | 少保留一些方向，会损失多少？ | 截断 SVD，计算并证明最佳平方重建误差。 |
| [24 PCA]({{< relref "/book/ch24" >}}) | 多特征数据，怎样找少数坐标？ | 中心化后选择变化最大的方向并重建。 |
| [25 最终重建]({{< relref "/book/ch25" >}}) | 忘记公式，还能从问题走回来吗？ | 用房价、迁移与双声道重建完整路线。 |
