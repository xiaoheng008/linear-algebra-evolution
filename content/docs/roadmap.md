这张路线图帮助你在需要时找到某个问题的讲解，不要求开始阅读前记住全部术语。正文会从具体尝试逐步走向一般结论；下图只是事后的索引，不是数学史时间线。

```text
多个未知量需要同时满足条件
  -> 逐个消元，暴露唯一解、无解、多个自由选择
  -> 系数与运算重复出现，压缩成矩阵
  -> 一组相关数值需要作为整体处理，形成向量
  -> 展开矩阵乘向量，发现输入坐标在加权组合矩阵列
  -> 追问所有可能输出，进入张成与空间
  -> 追问描述是否冗余，进入线性无关、基与维数
  -> 追问对象如何作用于输入，进入线性变换
  -> 追问可逆性、解的结构与变换的不变量
  -> 追问长度、角度和最佳近似，进入正交、投影与最小二乘
  -> 特征向量无法覆盖一般变换，转向奇异值分解
  -> 用低秩结构理解近似、降维与数据
  -> 从原问题重建整个系统
```

## 从具体到一般，我们怎样走？

第一至五章主要沿着一份配料记录推进：用量如何满足成分要求，方程怎样简化，成分表怎样成为矩阵，整份成分怎样成为向量；第三章另用房价说明同一张表可以从两个方向使用。每一步都先算具体数字，再写通用规则。

第四至六章把相同的计算用于绳索受力。第十三章先从两个数的和寻找不可见变化，再用四个输入、两个自由变量实际求出零空间基，最后回到三根绳子的全部张力与非负区间。第十八章先从误差与平方长度的交叉项理解内积，再用恒力做功作迁移，并沿用重复测量实际算出四个子空间。换场景时，我们检查坐标意义、单位与物理限制，确认哪些计算关系仍然成立。

最后只保留数学关系：任意实数系数、任意维数、一般矩阵，以及不依赖例子的证明。我们重建的是一条理解路径，不是在断言线性代数历史上一定由这些问题产生。

## 停下来重建

四组阶段练习：[方程与列组合]({{< relref "/book/exercises" >}})、[可达范围与解的自由度]({{< relref "/book/checkpoint-space" >}})、[反复作用与特征方向]({{< relref "/book/checkpoint-dynamics" >}})、[最佳近似与信息损失]({{< relref "/book/checkpoint-approximation" >}})。

每组都含陌生数字的计算、不提示工具的问题与错解诊断，并把方向提示与完整核对分开。先独立做，再打开提示；仅重做正文原例，不能判断是否已经学会迁移。

每个阶段结束时都应重建“前一概念为什么不够、下一概念如何补足”的关系，而不只复述术语。

## 主线需要哪些前提？

需要高中代数中的方程变形与坐标、勾股定理；不要求先学微积分或 Python。正文先手算，实验用于核对与改变条件。第一次接触代码时，可以先在 Colab 按顺序运行，再少量修改数值。

第十八章将长度与正交、四空间连接、谱定理延伸分开。谱定理的存在性证明使用极值与方向导数，可以暂时跳过；第二十二章的一般 SVD 存在性明确引用这个定理。请区分“算出一个例子”“理解构造过程”与“证明一般存在性”，不把实验运行成功当成最后一种。
