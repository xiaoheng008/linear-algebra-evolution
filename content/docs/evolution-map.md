这是教学用的认知依赖图，不是人物、年代或发现顺序的历史叙述。箭头表示前一个能力暴露了下一个问题。

```text
现实约束
  -> 线性方程：表达多个未知量之间的关系
  -> 消元：把约束系统化简为等价但更易读的形式
       -> 解的存在性、唯一性、自由变量
       -> 矩阵：压缩重复的系数结构和统一运算
            -> 向量：把一组输入或输出作为整体
                 -> Ax 的坐标展开
  -> 线性组合：解释输出是矩阵列的加权和
                      -> 张成：哪些输出可达？
                      -> 线性无关：描述中是否有冗余？
                           -> 基：最小而充分的方向描述
                           -> 维数：独立方向有多少？
                 -> 线性变换：矩阵表示的作用是什么？
                      -> 复合与矩阵乘法
                      -> 逆：作用能否撤销？
                      -> 列空间 / 零空间 / 秩 / 秩-零化度
                      -> 特征结构与对角化
                           -> 一般矩阵的局限
                           -> SVD
                                -> 低秩近似、降维、数据
                 -> 距离与内积
                      -> 正交与投影
                           -> 最小二乘
```

## Phase 1 的压力链

1. **线性方程**表达单个约束；多个约束同时出现后，逐条猜解不够可靠。
2. **消元**将系统变成等价的简单系统；消元结果又显示，系统不只“有一个解”或“没解”，还可能留下自由选择。
3. 系数与变量的运算模式反复出现；**矩阵**将系数表和统一规则压缩为一个对象。
4. 矩阵仍需要输入和输出；一组数作为整体参与运算时，**向量**提供简洁的对象表示。
5. 计算 `Ax` 并按输入坐标分组，会显露每一列如何参与输出；**线性组合**由此成为解释矩阵作用的语言。
6. [张成]({{< relref "/book/ch06" >}})回答了哪些目标能由给定列组合出来；[线性无关]({{< relref "/book/ch07" >}})接着检查列的描述里有没有重复方向。
7. [基]({{< relref "/book/ch08" >}})留下既能生成整个空间、又没有重复信息的一组向量；这让我们接着问：基的向量个数是否固定？

## 检查每个新概念

对图上的每个概念都追问：此前有哪些能力？它们在哪里变得笨重或失效？什么观察让新结构可见？新结构能做什么？它又暴露了什么问题？如果无法回答，就先不要把该概念作为教程中的新章。
